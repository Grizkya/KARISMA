# 🏛️ RaVenue — Unram Venue Reservation

*RaVenue* adalah platform berbasis web yang menggunakan next.js yang dirancang untuk mempermudah proses peminjaman gedung kampus di *Universitas Mataram (Unram)*.

---

# 🚀 Fitur Utama

##🔐 1. Autentikasi (Admin dan User)

Sistem autentikasi digunakan untuk mengatur akses pengguna berdasarkan admin atau user. User dapat melihat halaman utama (Home), mengajukan peminjaman, dan melihat status peminjaman. Sedangkan Admin dapat melihat daftar  tambahan yaitu menyetujui atau menolak persetujuan pengajuan
